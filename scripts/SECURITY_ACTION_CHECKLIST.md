# 安全问题处理清单

使用本清单系统地处理安全检查中发现的问题。

## 📋 处理流程

### 第一步：运行检查
- [ ] 运行安全检查脚本
  ```bash
  ./scripts/security-check.sh --all
  ```
- [ ] 查看生成的报告
  ```bash
  cat security-reports/security_check_*.md
  ```
- [ ] 记录发现的问题数量
  - 高风险: _____ 个
  - 中风险: _____ 个
  - 低风险: _____ 个

### 第二步：处理高风险问题（立即）

#### 🔴 个人信息泄露
- [ ] 确认文档是否包含真实个人信息
  - [ ] 姓名
  - [ ] 电话号码
  - [ ] 身份证号
  - [ ] 家庭住址
  - [ ] 其他个人信息

**处理方案**：
- [ ] 立即删除包含真实个人信息的文档
- [ ] 通知相关人员，避免再次上传
- [ ] 记录处理结果

#### 🔴 财务信息泄露
- [ ] 确认文档是否包含财务敏感数据
  - [ ] 工资表
  - [ ] 银行账号
  - [ ] 报价单（内部）
  - [ ] 预算表（未公开）
  - [ ] 财务报表（内部）

**处理方案**：
- [ ] 立即删除包含财务敏感数据的文档
- [ ] 评估潜在影响
- [ ] 通知相关部门
- [ ] 记录处理结果

#### 🔴 身份证号泄露
- [ ] 确认是否为真实身份证号
- [ ] 确认涉及人数

**处理方案**：
- [ ] 立即删除包含身份证号的文档
- [ ] 通知受影响人员
- [ ] 评估法律风险
- [ ] 记录处理结果

### 第三步：处理中风险问题（24小时内）

#### 🟡 Excel文件审查
对于每个Excel文件：
- [ ] 下载文件到本地
- [ ] 打开并审查内容
- [ ] 检查是否包含：
  - [ ] 个人信息
  - [ ] 财务数据
  - [ ] 内部统计数据
  - [ ] 未公开的业务数据

**处理方案**：
- [ ] 如包含敏感信息 → 删除
- [ ] 如为公开数据 → 保留并记录
- [ ] 如不确定 → 咨询相关部门

#### 🟡 保密关键词文档
对于包含"密"、"保密"等关键词的文档：
- [ ] 打开文档查看完整内容
- [ ] 确认文档类型：
  - [ ] 公开的法律法规
  - [ ] 政府公开文件
  - [ ] 内部涉密文件
  - [ ] 其他

**处理方案**：
- [ ] 公开法律法规 → 保留，添加到白名单
- [ ] 内部涉密文件 → 立即删除
- [ ] 不确定 → 咨询法务或安全部门

#### 🟡 内部标识文档
对于标记为"内部使用"、"仅限内部"的文档：
- [ ] 确认文档是否适合对外公开
- [ ] 评估公开的潜在影响

**处理方案**：
- [ ] 不适合公开 → 删除或设置访问权限
- [ ] 可以公开 → 去除内部标识后保留
- [ ] 不确定 → 咨询相关部门

### 第四步：处理低风险问题（一周内）

#### 🟢 联系方式
对于包含联系方式的文档：
- [ ] 确认联系方式类型
  - [ ] 政府部门公开电话
  - [ ] 企业公开联系方式
  - [ ] 个人私人号码
  - [ ] 内部联系方式

**处理方案**：
- [ ] 公开联系方式 → 保留，添加到白名单
- [ ] 私人号码 → 删除或脱敏
- [ ] 内部联系方式 → 评估后决定

#### 🟢 邮箱地址
对于包含邮箱的文档：
- [ ] 确认邮箱类型
  - [ ] 公开联系邮箱
  - [ ] 个人私人邮箱

**处理方案**：
- [ ] 公开邮箱 → 保留
- [ ] 私人邮箱 → 删除或脱敏

### 第五步：建立预防机制

#### 短期措施（1-2周）
- [ ] 制定文档上传审核流程
- [ ] 对文档上传者进行安全培训
- [ ] 建立敏感信息识别指南
- [ ] 配置定期自动检查（每周）

#### 中期措施（1个月）
- [ ] 建立文档分类体系
- [ ] 实施访问权限控制
- [ ] 建立安全检查白名单
- [ ] 定期审查和更新检查规则

#### 长期措施（持续）
- [ ] 持续运行定期安全检查
- [ ] 定期安全培训和意识提升
- [ ] 持续优化检查规则
- [ ] 建立安全事件响应流程

## 🔍 审查要点

### Excel文件审查要点
1. **第一眼检查**
   - 文件名是否包含敏感关键词
   - 工作表名称是否暴露敏感信息

2. **内容检查**
   - 是否包含姓名列
   - 是否包含电话/身份证列
   - 是否包含金额/账号列
   - 是否包含内部编号/代码

3. **数据量评估**
   - 数据行数
   - 涉及人数
   - 潜在影响范围

### 文档内容审查要点
1. **敏感信息识别**
   - 个人身份信息
   - 联系方式
   - 财务数据
   - 内部业务数据

2. **文档性质判断**
   - 公开发布的文件
   - 内部使用文件
   - 草稿/未定稿
   - 历史版本

3. **公开适宜性评估**
   - 是否涉及商业秘密
   - 是否涉及个人隐私
   - 是否符合公开要求

## ⚠️ 注意事项

1. **处理优先级**
   - 高风险问题必须立即处理
   - 中风险问题24小时内处理
   - 低风险问题一周内处理

2. **删除操作**
   - 删除前务必确认
   - 保留删除记录
   - 通知相关人员

3. **不确定情况**
   - 不确定时不要擅自决定
   - 及时咨询相关部门
   - 记录咨询过程

4. **持续改进**
   - 定期回顾处理记录
   - 总结经验教训
   - 优化检查规则
