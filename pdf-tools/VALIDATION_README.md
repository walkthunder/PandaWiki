# 输出验证和整理工具

## 概述

这个工具用于验证和整理 PDF 转 Markdown 的输出文件，自动检查文件有效性并组织文件结构。

## 功能

### ✅ 自动检查

1. **MD 文件验证**
   - 检查文件是否为空
   - 检查内容是否过少（< 100 字符）
   - 检查是否有实际内容（排除只有标题和分隔符的文件）

2. **图片链接验证**
   - 扫描 MD 文件中的图片引用
   - 识别有效图片（被 MD 文件引用）
   - 识别孤立图片（未被任何 MD 文件引用）

### 📁 自动整理

- **有效文件** → `outputs/valid/`
  - 有效的 MD 文件
  - 被引用的图片文件
  
- **无效文件** → `outputs/invalid/`
  - 无效的 MD 文件（空文件或内容过少）
  - 孤立的图片文件（未被引用）

### 📊 生成报告

自动生成 `validation_report.md`，包含：
- 总体统计信息
- 转换成功率
- 有效文件列表
- 无效文件列表及原因
- PDF 对应关系表
- 文件组织说明
- 改进建议

## 使用方法

### 方式 1: 使用 Shell 脚本（推荐）

```bash
./validate_outputs.sh
```

### 方式 2: 直接使用 Python

```bash
python3 validate_and_organize.py
```

### 方式 3: 指定输出目录

```bash
./validate_outputs.sh --output-dir /path/to/outputs
```

## 建议

### 对于无效文件

1. 检查对应的 PDF 文件是否正常
2. 尝试重新转换这些 PDF 文件
3. 如果 PDF 本身内容就很少，可能是正常的

### 对于孤立图片

1. 可以安全删除 `outputs/invalid/` 中的孤立图片
2. 或者保留一段时间，以防需要手动恢复

### 对于有效文件

1. 有效文件已整理到 `outputs/valid/` 目录
2. 图片链接保持相对路径，可以正常显示
3. 可以直接使用这些文件

## 技术细节

### MD 文件有效性判断标准

1. 文件不为空
2. 内容长度 ≥ 100 字符
3. 去除标题、分隔符后的实际内容 ≥ 50 字符

### 图片引用检测

使用正则表达式匹配 Markdown 图片语法：
```
!\[.*?\]\(([^)]+\.png)\)
```

### 文件组织策略

- 保持原始文件不变
- 复制文件到新目录
- 保持图片的相对路径引用有效
