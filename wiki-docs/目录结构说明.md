# PandaWiki 目录结构说明

本文档说明仓库各目录的职责，便于定位代码与扩展功能。

## 1. 根目录

```
PandaWiki/
├── .github/                 # CI/CD、Issue/PR 模板
├── backend/                 # 后端服务（Go）
├── web/                     # 前端 Monorepo（pnpm workspace）
├── sdk/                     # 对外/内部 SDK
├── images/                  # README 等展示用图片资源
├── wiki-docs/               # 本仓库架构与结构文档（本地整理）
├── README.md                # 产品介绍与上手指南
├── PROJECT_STRUCTURE.md     # 官方简版结构说明
├── CONTRIBUTING.md          # 贡献指南
├── CODE_OF_CONDUCT.md       # 行为准则
├── SECURITY.md              # 安全策略
└── LICENSE                  # AGPL-3.0
```

| 路径 | 作用 |
|------|------|
| `.github/` | GitHub Actions（`backend.yml` / `web.yml` 等）、Issue 模板 |
| `backend/` | HTTP API、消息消费、数据库迁移、业务逻辑与基础设施 |
| `web/` | 控制台（admin）、Wiki 前台（app）、共享 UI/主题/图标包 |
| `sdk/` | 与 RAG 服务交互的 Go SDK |
| `images/` | 文档配图（banner、截图、安装示意等） |
| `wiki-docs/` | 项目目录与技术架构梳理文档 |

---

## 2. 后端 `backend/`

后端采用清晰分层：入口（cmd）→ 传输层（handler/middleware）→ 用例（usecase）→ 领域（domain）→ 仓储（repo）→ 存储适配（store）。依赖注入使用 Google Wire。

### 2.1 顶层目录

| 目录/文件 | 作用 |
|-----------|------|
| `cmd/` | 可执行程序入口 |
| `handler/` | HTTP / MQ 处理器，对接路由与请求响应 |
| `middleware/` | 认证、会话、只读模式等中间件 |
| `usecase/` | 业务用例编排（知识库、文档、对话、爬虫、机器人等） |
| `domain/` | 领域模型、DTO、错误与通用响应结构 |
| `repo/` | 仓储接口实现（按存储介质分子目录） |
| `store/` | 底层存储客户端初始化（PG / Redis / S3 / RAG / IPDB） |
| `api/` | API 相关辅助模块（按业务域划分：kb、node、auth 等） |
| `mq/` | 消息队列抽象与 NATS 实现 |
| `pkg/` | 第三方集成封装（钉钉、飞书、企微、OAuth、LDAP、验证码等） |
| `server/` | HTTP 服务器装配（Echo） |
| `config/` | 配置加载（Viper） |
| `consts/` | 常量 |
| `migration/` | 迁移相关逻辑与迁移函数 |
| `setup/` | 安装/初始化（如证书检查） |
| `log/` | 日志封装 |
| `apm/` | 应用性能监控相关 |
| `telemetry/` | OpenTelemetry 等遥测 |
| `utils/` | 通用工具函数 |
| `docs/` | Swagger 生成物（`swagger.yaml` / `docs.go`） |
| `pro/` | 专业版能力（Git Submodule，独立仓库） |
| `Dockerfile.api` / `Dockerfile.consumer` | API / Consumer 镜像构建 |
| `Makefile` | 代码生成（swag/wire）、镜像构建、本地 compose 等 |
| `go.mod` / `go.sum` | Go 模块依赖 |

### 2.2 `cmd/` 三个进程

| 子目录 | 职责 |
|--------|------|
| `cmd/api` | HTTP API 服务入口，对外提供管理端与 Share/OpenAPI |
| `cmd/consumer` | 消息队列消费者，处理异步任务（如 RAG 文档更新、定时任务） |
| `cmd/migrate` | 数据库迁移入口 |

### 2.3 `handler/` 请求入口

| 子目录 | 职责 |
|--------|------|
| `handler/v1/` | 管理端 / 内部 V1 API（用户、知识库、文档节点、模型、爬虫、会话、评论等） |
| `handler/share/` | 面向 Wiki 前台与分享场景的接口（聊天、节点、验证码、微信、OpenAPI 等） |
| `handler/mq/` | MQ 消费处理（RAG、文档更新、Cron 等） |

### 2.4 `repo/` 与 `store/`

| 路径 | 职责 |
|------|------|
| `repo/pg` | PostgreSQL 数据访问 |
| `repo/cache` | Redis 等缓存访问 |
| `repo/mq` | 消息队列仓储/发布相关 |
| `repo/ipdb` | IP 地理库访问 |
| `store/pg` | GORM/PG 连接与 SQL 迁移文件 |
| `store/cache` | Redis 客户端 |
| `store/s3` | MinIO / S3 对象存储 |
| `store/rag` | RAG 服务客户端封装 |
| `store/ipdb` | IP 库初始化 |

### 2.5 `pkg/` 集成包

| 包 | 职责 |
|----|------|
| `dingtalk` / `feishu` / `wecom` | 钉钉、飞书、企业微信集成 |
| `bot` | 聊天机器人通用能力 |
| `oauth` | OAuth 登录 |
| `ldap` | LDAP 认证 |
| `cas` | CAS 相关 |
| `captcha` | 验证码 |
| `anydoc` | 文档导入/转换相关 |

### 2.6 `usecase/` 主要业务

覆盖但不限于：知识库、文档节点、LLM/模型、聊天问答、爬虫与 Sitemap、文件、统计、评论、创作、钉钉/微信机器人、用户与认证等。

## 3. 前端 `web/`

使用 **pnpm workspace** 管理多包：

```yaml
# pnpm-workspace.yaml
packages:
  - 'app'
  - 'admin'
  - 'packages/*'
```

### 3.1 顶层

| 路径 | 作用 |
|------|------|
| `admin/` | 控制台（Vite + React + React Router） |
| `app/` | Wiki 网站前台（Next.js App Router） |
| `packages/` | 共享包：`ui` / `themes` / `icons` |
| `package.json` | 根脚本（并行 build/dev）、共享依赖 |
| `.husky/` | Git hooks（配合 lint-staged + Prettier） |

### 3.2 `web/admin`（控制台）

面向管理员：知识库管理、文档编辑、发布、统计、会话、反馈、设置等。

| 路径 | 作用 |
|------|------|
| `src/pages/` | 页面：login、document、release、stat、conversation、feedback、setting、contribution 等 |
| `src/components/` | 业务组件（KB、编辑器相关、图表、上传、拖拽树等） |
| `src/store/` | Redux Toolkit 状态 |
| `src/api/` / `src/request/` | API 封装与请求层（含 pro） |
| `src/layouts/` | 布局 |
| `src/hooks/` / `src/services/` | Hooks 与业务服务 |
| `api-templates/` | Swagger 生成 API 的模板配置 |
| `scripts/` | 工具脚本（如图标下载） |

### 3.3 `web/app`（Wiki 前台）

面向最终用户：文档阅读、搜索/问答、挂件、H5 聊天、反馈等。

| 路径 | 作用 |
|------|------|
| `src/app/` | Next.js App Router 路由与布局 |
| `src/app/(pages)/` | 文档页等主业务路由组 |
| `src/app/widget/` | 网页挂件入口 |
| `src/app/h5-chat/` | 移动端聊天页 |
| `src/app/feedback/` | 反馈相关页 |
| `src/components/` | 目录、Markdown 渲染、页头页脚、问答弹层等 |
| `src/request/` | 对后端 Share API 的请求封装 |
| `src/middleware/` | Next.js 中间件 |
| `src/provider/` | React Context / Provider |
| `public/` | 静态资源 |

### 3.4 `web/packages`（共享包）

| 包名 | 作用 |
|------|------|
| `@panda-wiki/ui` | 可复用 UI 组件（含动效等依赖） |
| `@panda-wiki/themes` | 主题与主题类型定义 |
| `@panda-wiki/icons` | 图标资源与生成脚本 |

根 `web/package.json` 还共享 React 19、MUI 7、Emotion、`@ctzhian/tiptap` 富文本等依赖。

## 4. SDK `sdk/`

```
sdk/
└── rag/          # RAG 服务 Go 客户端
    ├── client.go
    ├── dataset.go
    ├── document.go
    ├── chunk.go
    ├── retrieval.go
    ├── model_config.go
    └── models.go
```

`backend` 通过 `github.com/chaitin/pandawiki/sdk/rag` 依赖该模块，用于数据集、文档、分块、检索与模型配置等 RAG 能力。
